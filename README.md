## 🧠 Topics Covered

- **C Fundamentals:** Functions, recursion, structures and arrays
- **Linked Lists:** Singly, doubly and circular linked lists
- **Stacks & Queues:** Array and linked-list implementations
- **Stack Applications:** Infix-to-postfix conversion and expression evaluation
- **Deque:** Array and linked-list implementations
- **Searching:** Linear and binary search
- **Sorting:** Bubble, selection, insertion and quick sort

## 🛠️ Tech Stack

- **Language:** C
- **Compiler:** GCC
- **Tools:** VS Code, Git & GitHub

## ▶️ Compile & Run

Compile a program using GCC:

```bash
gcc D09_Q01.c -o output
```

Run on Linux/macOS:

```bash
./output
```

Run on Windows:

```bash
output.exe
```
